# ①課題名
ねこの体調メモアプリ

## ②課題内容（どんな作品か）

* 猫の毎日の体調（ごはん・ご機嫌・うんち・おしっこ・体重・メモ）を、タップするだけで記録できるメモアプリです。
* 記録はブラウザの localStorage に保存され、記録一覧・体重グラフ・カレンダーで体調の変化をふり返ることができます。

* PW: なし

## ⑤工夫した点・こだわった点

* 入力を簡単にするため、選択肢をクリックして選べるようにしました。
* 複数の項目をまとめて保存するため、JSON.stringify / JSON.parse を使って1日分を1件として保存しています。同じ日付で再セーブすると上書きされ、修正もできます。
* セーブ後は入力欄が空になるようにしました
* 体重グラフはcanvas APIで描きしました。カレンダーは記録した日に🐾が付き、タップするとその日の記録を読み込めます。

## ⑥難しかった点・次回トライしたいこと（又は機能）

* 難しかった点：localStorage に文字列しか保存できないため、複数の項目をJSONにして保存・読み込みするところ。
* 難しかった点：JavaScriptで作ったカレンダーの日付にクリックイベントを付けるところ（`$(document).on` を使う必要があった）。
* 次回トライしたいこと：多頭飼いに対応して、猫ごとに記録を分ける機能。
* 次回トライしたいこと：写真の添付や、病院で見せるための1週間まとめ画面。
